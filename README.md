# ناسخ

**برنامج البحث في مكتبة «الجامع» ونسخ النتائج إلى Word.**

يبحث «ناسخ» في مكتبة [الجامع](https://aljam3.com) الإسلامية (أكثر من ٦٣ ألف كتاب)،
ثم تحدّد النتائج التي تريدها وتضغط زرًّا واحدًا فتُنسَخ كلها إلى ملف Word
منسّقة، وكل نصّ متبوعٌ بتخريجه (اسم الكتاب والمؤلف ورقم الصفحة) ورابط المصدر.

> سُمِّي «ناسخ» لأنه ينسخ النتائج من الجامع إلى Word مباشرة — وهي ميزة غير متوفرة في المواقع.

---

## للزملاء (الاستخدام فقط)

لا تحتاج تثبيت أي شيء:

1. افتح `ناسخ.exe` بنقرة مزدوجة.
2. اكتب العبارة واضغط **ابحث**.
3. حدّد النتائج (نقر مزدوج على الصف، أو **تحديد الكل**).
4. اضغط **📄 نسخ المحدَّد إلى Word**.
5. اختر مكان الحفظ → يُنشأ ملف Word ويُفتح.

> يحتاج البرنامج اتصالًا بالإنترنت (يبحث مباشرة في موقع الجامع).

---

## إنشاء ملف الـ exe (مرة واحدة)

على جهاز ويندوز:

1. ثبّت [بايثون](https://www.python.org/downloads/) مع تفعيل **"Add Python to PATH"**.
2. انقر نقرًا مزدوجًا على `build_exe.bat`.
3. ستجد الملف الجاهز في `dist\ناسخ.exe`.
4. وزّع `ناسخ.exe` وحده على الزملاء.

### أو التشغيل للتجربة (بدون exe)

```bash
pip install -r requirements.txt
python app.py
```

---

## الملفات

| الملف | الوظيفة |
|------|---------|
| `app.py` | الواجهة الرسومية وزر النسخ إلى Word |
| `aljam3.py` | الاتصال بواجهة الجامع (REST API) والتخريج |
| `build_exe.bat` | إنتاج `ناسخ.exe` بنقرة واحدة |
| `requirements.txt` | المكتبات المطلوبة |
| `دليل_الاستخدام.txt` | دليل عربي مبسّط |

---

## المصدر وأمانة علمية

يعتمد البرنامج على [واجهة الجامع الرسمية](https://github.com/ieasybooks/aljam3-web-app) (مفتوحة المصدر، بلا مفتاح).

رقم الصفحة يخصّ النسخة الرقمية وقد يختلف عن ترقيم المطبوع، والجامع لا يوفّر
بيانات الناشر/الطبعة/درجة الحديث؛ فتُراجَع الطبعة المطبوعة عند الحاجة للتوثيق الدقيق.
